# Productos de prueba para Postman

Usa `POST http://localhost:3000/api/productos`, con Basic Auth (`BASIC_AUTH_USER` y `BASIC_AUTH_PASS`) y **Body → raw → JSON**. Copia y envía cada objeto por separado. Precios y cantidades ilustrativos; ajústalos al inventario real.
